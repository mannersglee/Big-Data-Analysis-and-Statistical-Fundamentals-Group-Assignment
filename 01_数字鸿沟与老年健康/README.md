# 数字鸿沟与老年健康

## 数据与问题

使用本仓库 CHARLS 2020 全国追踪调查 `Health_Status_and_Functioning.dta` 与 `Demographic_Background.dta`，按受访者 ID 一对一合并。原始健康模块有 19,367 条记录、远超 10 个变量。本题观察 60 岁及以上人群中，使用互联网与自评健康的关系。

## 变量口径

- `xrage`：年龄，筛选 60–110 岁。
- `da040`：是否使用互联网，1=是、2=否。
- `da001`：自评健康，1–5 为有效选项；1 或 2 定义为“健康较好”。
- `xrgender`：性别，1=男、2=女。
- `ba008`：居住地类别（1–3），作为分类控制变量。
- 997 及其他非有效选项视为缺失。描述统计和回归均使用完整案例。

## 分析流程

读取压缩包内 Stata 文件 → 按 ID 合并 → 清理编码与缺失 → 样本量检查 → 上网/未上网分组描述 → Logistic 回归（控制年龄、性别、居住地）→ 输出 CSV 和 PNG。未使用抽样权重，结果是样本描述与探索性关联，不代表因果效应或严格的全国总体估计。

## 运行

```bash
/opt/anaconda3/envs/myenv/bin/python 01_数字鸿沟与老年健康/analyze.py
```

`output/` 包含分析样本、缺失概览、分组汇总、回归系数及图表。原始数据保留在 `../data/`，没有复制到本目录。当前运行有效样本为 9,447。分组“健康较好”比例：未上网约 20.7%，上网约 23.8%。年龄等变量调整后的上网优势比约 1.09；应结合 `logit_coefficients.csv` 中的置信区间和 p 值解释。
