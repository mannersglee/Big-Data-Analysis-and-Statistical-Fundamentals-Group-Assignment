# 大数据分析统计基础 期中大作业

## 作业要求

- 数据集:自选数据集(来源清晰可靠的)，围绕中国问题的现实数据
1. 数据集3000个样本以上，10个变量以上(定性定量都要有)。
2. 先介绍数据集的基本情况，再从该数据集中自选指标，自选数据，自选主题，做一个有逻辑的分析PPT。(最好用到已学习的抽样、数据预处理、可视化知识点)展示时长根据组数而定。不超过15分钟。

## 候选选题一：数字鸿沟与老年健康

- [数字鸿沟与老年健康](01_数字鸿沟与老年健康/README.md)：CHARLS 2020，60 岁及以上人群的上网与自评健康。

## 候选选题二：家庭背景与教育公平

- [家庭背景与教育公平](02_家庭背景与教育公平/README.md)：CEPS 2014–15，家庭经济条件与数学成绩。

## 候选选题三：流动人口城市融入

- [流动人口城市融入](03_流动人口城市融入/README.md)：CMDS 2017，居住年限、本地交往与身份认同。

## 候选选题四：收入差距与公平感

- [收入差距与公平感](04_收入差距与公平感/README.md)：CGSS 2021，个人收入位置与社会公平感。


## 图表复现

四篇报告的图表统一由 [绘图脚本](src/make_figures.py)生成，使用学术简洁配色，并同时导出 PNG 和可编辑的 SVG。先运行各选题 `analyze.py`，再运行前三篇所需的 `src/advanced_analysis.py`，最后运行：

```bash
/opt/anaconda3/envs/myenv/bin/python src/make_figures.py
```

图中的区间和预测指标都有相应口径说明；未加权的区间不包含复杂抽样设计不确定性。

四篇报告的 `N / Mean / SD / Min / P25 / P50 / P75 / Max` 分布表由 [描述统计脚本](src/descriptive_tables.py)生成。运行各选题 `analyze.py` 后执行：

```bash
/opt/anaconda3/envs/myenv/bin/python src/descriptive_tables.py
```
