## Python 实现

- [数字鸿沟与老年健康](01_数字鸿沟与老年健康/README.md)：CHARLS 2020，60 岁及以上人群的上网与自评健康。
- [家庭背景与教育公平](02_家庭背景与教育公平/README.md)：CEPS 2014–15，家庭经济条件与数学成绩。

使用 `/opt/anaconda3/envs/myenv/bin/python` 运行各目录下的 `analyze.py`。脚本依赖当前环境已安装的 pandas、matplotlib、statsmodels；结果写入各自的 `output/` 目录。
- [流动人口城市融入](03_流动人口城市融入/README.md)：CMDS 2017，居住年限、本地交往与身份认同。

三篇报告另有统一的[扩展分析脚本](src/advanced_analysis.py)，用于固定划分的测试集模型比较与倾向评分加权诊断。在三个选题的 `analyze.py` 生成分析样本后运行：

```bash
/opt/anaconda3/envs/myenv/bin/python src/advanced_analysis.py
```

论文中的加权结果仅作为观察性敏感性分析；机器学习指标来自独立留出测试集。
