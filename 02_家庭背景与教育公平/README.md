# 家庭背景与教育公平

## 数据与问题

使用本仓库 CEPS 2014–15 追访调查学生问卷 Stata 数据，原始样本 10,750 人、311 个变量。研究家庭经济状况与数学成绩的关系，并考察家庭藏书和电脑网络资源。数据来自中国教育追踪调查（CEPS），详见 `../data/CEPS数据合集/CEPS14-15追访/数据使用手册 .pdf`。

## 变量口径

- `w2mat / w2upmat × 100`：2014 年秋季期中数学成绩占试卷满分百分比；仅保留 0–100。
- `w2a09`：学生自评家庭经济条件，五级有序分类。
- `w2a11`：家庭藏书数量，五级有序分类。
- `w2a12`：家中有无电脑及网络；“有电脑和网络”为 1，其余有效选项为 0。
- `w2sweight`：学生截面权重，随清洗样本导出，当前描述和回归未使用。
- 原始中文标签在 Stata 文件中出现乱码，脚本用 Latin-1→GBK 修复后映射；无法识别的选项不进入完整案例。

## 分析流程

从 ZIP 读取 DTA → 修复标签 → 计算数学成绩百分比 → 清理缺失 → 家庭经济条件分组统计 → OLS 回归（纳入藏书和电脑网络资源，HC3 稳健标准误）→ 输出 CSV 和 PNG。家庭经济条件为主观评价，且分析为观察性横截面关联；不能推出家庭背景对成绩的因果影响。

## 运行

```bash
/opt/anaconda3/envs/myenv/bin/python 02_家庭背景与教育公平/analyze.py
```

`output/` 包含分析样本、缺失概览、分组汇总、回归系数和图表。当前运行有效样本为 8,789。各组样本量差异大，“很富裕”组仅 70 人，展示时应同时报告组样本量，避免单看均值。
